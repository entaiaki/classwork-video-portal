# Rewritten Minds at Work — 2D preview

Version: `CV-A2-12-COPY-2D-20261117`  
Scheme: `CV-A2-12-scheme-v2` (Psychology × Economic)

This folder is a **work-in-progress 2D preview** of an Assignment Two project (*Rewritten Minds at Work* / 《被改写的劳动心智》). It is the inspection-bench-first fallback: the thesis, three cases, four-column comparison, and three-condition judgments work without WebGL.

How to open:

- On GitHub Pages, use the `/a2/` path of this repository (for example `.../classwork-video-portal/a2/`).
- Locally, open `index.html`, or serve the parent directory so this folder is reached as `/a2/`.

`a2/content/inspection-bench.json` is the locked source copy (from this folder, `content/inspection-bench.json`). The same JSON is already embedded in `index.html`, so the preview does not need a network request.

What this preview is not:

- 3D scenes and WebGL are **not** included. The 3D control on the page is disabled on purpose.
- Independent quality review and live UX review are in progress and have **not** been completed. Publishing this preview is not an acceptance pass and is not the final course submission.
- A 60-second demo recording and the separate English slide deck are not part of this folder.

This `/a2/` path is separate from the classwork video portal homepage and does not replace it.
